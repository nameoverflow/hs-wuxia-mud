# 角色养成系统设计

本文定义长线养成模型：玩家怎么变强、变强要付出什么、什么东西限制成长速度。核心原则不变：角色本身没有等级，长期成长落在武功等级与熟练度、潜能、实战经验和内力上限上。

角色先天属性、资源上限和战斗派生公式见 [角色属性与派生数值设计](./character-attributes.md)。本文负责成长规则、各养成动作的成本与上限、成长资源的来源与消耗，以及节奏目标。文末单列当前实现与本设计的差距和落地顺序。

## 设计目标

- 角色无全局等级。强弱由武功、内力、实战经验、装备和后续心法共同表达。
- 所有可成长能力都表示为武功或基础功等级。
- 每个养成动作承担不同角色，付出不同代价，没有一个动作能替代其他所有动作。
- 成长速度由“上限”和“资源”两类约束共同决定：上限回答“现在最多能练到哪”，资源回答“还要付出多少”。
- 学习门路跟剧情身份绑定：去哪学、跟谁学、对方认不认你，比属性点更能决定路线。
- 不设悟性或任何学习效率先天属性，理由见属性文档。
- 战斗、剧情和江湖差事都能推动成长；单纯对着木人刷不应是最优解。

## 成长轴总览

| 轴 | 表示 | 主要用途 | 主要来源 |
| --- | --- | --- | --- |
| 武功 | 每门武功的 `level + progress` | 招式解锁、战斗派生数值 | learn / practice / study / research |
| 基础功 | `type: foundation` 的武功等级 | 学习门槛、派生属性底座、practice 上限 | 具体武功带动、武馆学习 |
| 内力 | 长期 `storedMaxQi` | 主动招式、疗伤、内功效果 | meditate、剧情、奇遇 |
| 实战经验 | `combat_exp` | 武功等级上限、少量 HP/Jing 加成 | 战斗、江湖差事、剧情 |
| 潜能 | `potential` | learn / research 的消耗货币 | 战斗、江湖差事、剧情 |
| 门路 | 剧情 flag 与师承关系 | 决定谁肯教、教到几级 | 剧情、门派 |

心法（Technique/Xinfa）是装备实例之后的第二成长轴，本文只约定它不改变武功规则，只经 `DerivedStats` 和主动招式管线进入战斗。

## 分类模型

`MartialArt` 使用 `type` 表示大类：

```yaml
type: foundation | internal | lightness | sword | fist
```

每门武功字段：

```yaml
id: weiyuan_sword
name: "威远剑法"
type: sword
tier: entry            # entry | regional | lineage，见“武学分阶”
desc: "..."
foundation: basic_sword
requires:
  - art: basic_sword
    level: 1
max_level: 20
research_from: 10      # 可选，默认 ceil(max_level / 2)
attack_moves: []
active_skills: []
```

玩家已学武功记录为 `ArtEntity`：

```yaml
id: weiyuan_sword
level: 3
progress: 45
```

## 等级上限栈

一门武功能不能再升一级，看同时成立的几条上限，取最小值：

| 上限 | 规则 | 作用 |
| --- | --- | --- |
| 武功上限 | `level <= max_level` | 入门武功天花板低，绝学天花板高 |
| 实战上限 | `combat_exp >= expRequired(level)` | 没有实战，练不上去 |
| 来源上限 | 每个动作自己的上限，见下节 | 区分各动作的角色 |

实战上限改为三次曲线：

```text
expRequired(L) = ceil(L^3 / 10)
```

| 等级 | 需要实战经验 |
| --- | --- |
| 5 | 13 |
| 10 | 100 |
| 20 | 800 |
| 30 | 2700 |
| 40 | 6400 |
| 60 | 21600 |
| 100 | 100000 |

前期门槛很低，几场战斗就能放开；后期每级需要的实战明显变多，长线由实战拉开。

## 熟练度

每次养成动作只给熟练度，不再直接给一整级。熟练度满了才升级，溢出部分保留到下一级。

```text
progressRequired(L) = 10 * L + 20      # 从 L-1 升到 L 需要的熟练度
```

| 目标等级 | 本级所需 | 从 1 级累计 |
| --- | --- | --- |
| 10 | 120 | 720 |
| 20 | 220 | 2470 |
| 30 | 320 | 5220 |
| 60 | 620 | 19470 |
| 100 | 1020 | 52470 |

熟练度改成线性增长后，长线成本主要由实战上限和资源消耗承担，前期升级不会慢得无聊。

## 养成动作

| 动作 | 定位 | 成本 | 每次熟练度 | 来源上限 | busy |
| --- | --- | --- | --- | --- | --- |
| `learn` | 跟师父学，快 | 1 潜能 + Jing `12 + L/2` | `12 + teacherBonus` | 师父可教上限（受师承层级影响） | 2 秒 |
| `study` | 读秘籍，不花潜能 | Jing `18 + L/2` | `10 + 2 * book.quality` | 秘籍等级带 `[min_level, max_level]` | 3 秒 |
| `practice` | 自己练，不花潜能，慢 | Jing `6 + L/4`，外加 HP 或 Qi | `4 + foundation / 10` | 不超过对应基础功等级 | 3 秒 |
| `research` | 自研，学无可学之后的路 | 1 潜能 + Jing `20 + L` | `20 + insightBonus` | 武功等级 ≥ `research_from` 才能开始 | 4 秒 |
| `meditate` | 打坐，涨内力上限 | 当前 Qi + Jing | 不涨熟练度 | `storedMaxQi` 上限，见“内力” | `amount / 20` 秒，2 到 10 秒 |

规则：

- `L` 为该武功当前等级。所有除法向下取整。
- 每个动作都受实战上限约束：已到实战上限时，熟练度最多攒到本级满值减 1，不升级，并提示“缺乏实战”。
- `teacherBonus` 来自师父质量和师承关系（0 到 8），不来自玩家属性。
- `insightBonus` 第一版为 0，后续可由近期战斗、敌人类型、门派特性提供。
- `practice` 的附加成本：拳脚、剑法扣 HP `max 0 (8 + L/2 - vit/4)`；内功扣 Qi `10 + L/2`；轻功只扣 Jing。
- 精神或资源不足、到达上限时停止，并返回结构化原因。

### 连续动作

手机端不应要求玩家点一百次。每个养成动作支持次数参数：

```json
{"practice":{"art":"weiyuan_sword","times":20}}
{"learn":{"teacher":"kaifeng_martial_instructor","art":"basic_sword","times":10}}
```

- 服务端把多次动作排进 busy 队列，每完成一次结算一次。
- 中途资源不足、到达上限或进入战斗时停止，之前完成的次数保留，并返回实际完成次数和停止原因。
- 不再整体回滚：现在 `learn times=5` 第 3 次失败会让前两次一起作废。

## 基础功

基础功是 `type: foundation` 的武功，默认由角色模板授予：基础内功、基础轻功、基础剑法、基础拳法，`max_level: 100`。

### 基础功的成长

基础功不能 `practice` 或 `research`。它有两个来源：

1. **具体武功带动**：同门具体武功每获得熟练度，对应基础功同时获得一半熟练度。把简单剑法练深，剑法根基自然变厚；同一类型练多门武功，根基也都有积累。
2. **武馆学习**：武馆、驿站等地的师父可以用 `learn` 直接教基础功（见剧情大纲“门户与武学”），是用潜能换时间的捷径。

### practice 的上限与回流

`practice` 不能把具体武功练过对应基础功的等级。武功等级已经等于基础功等级时，再 `practice` 获得的熟练度全部流向基础功（“练到瓶颈，功力回到根基”）。

于是只靠自练时，武功和基础功交替上升，不会卡死；用 learn、study、research 可以让武功暂时领先基础功，但之后再想自练，就得先把根基补上来。

### 基础功的作用

- 学习更高阶武功的门槛。
- 派生属性：基础拳法、轻功、内功每 20 级提供 1 点臂力、身法、根骨（见属性文档）。
- 基础剑法、拳法进入命中和伤害；基础内功、轻功进入内力强度和身法强度。
- 不进入启用槽，战斗不直接出基础功的招式。

## 武学分阶

内容按三阶制作，门槛写成基础功等级，而不是“基础功 1 级”：

| 阶 | 例子 | `max_level` | 学习门槛 | 门路 |
| --- | --- | --- | --- | --- |
| 入门 `entry` | 无名试剑、无名试拳、镖局短打、威远剑法 | 10 到 20 | 对应基础功 1 级 | 新手剧情、武馆、秘籍 |
| 地域 `regional` | 洛阳剑法、茶马护身拳、太湖调息、烟水步 | 40 到 60 | 对应基础功 10 到 15 级 | 城市门户 flag + 本地师父 |
| 门派绝学 `lineage` | 后续少林、武当、五岳与段氏家传 | 80 到 120 | 对应基础功 30 级以上，可能附加另一门武功等级 | 入室弟子或奇遇 |

世界校验时检查：`regional` 及以上的武功必须声明至少一条 `requires.level > 1`。

## 门路与师承

谁肯教、教到几级，由剧情身份决定，而不是潜能多少：

| 关系 | 获得方式 | 可教上限 |
| --- | --- | --- |
| 路人 | 无 | 不教 |
| 挂名、门户认可 | 剧情 flag，例如武馆挂名学徒、`luoyang.name_card`、`dali.duan_trusted`、`taihu.pavilion_guest` | 该师父 `teaches` 上限的一半 |
| 记名 | 本地差事积累（贡献或 streak），后续门派系统 | `teaches` 上限 |
| 入室 | 拜师（门派系统） | 本门绝学全程，`teacherBonus` 提高 |

- NPC YAML 继续用 `teaches` 与 `teach_requires`，后续把单个 flag 扩成按层级的条件列表。
- 第一版只实现“挂名/门户认可”这一层：它就是现在的 `teach_requires`。
- 私学他派武功（例如通过剑谱学到的威远剑法）只能经 `study` 学到秘籍等级带的上限，再往上只能 `research`，或者找到肯认你的威远中人。这给后续剧情回响留下自然的触发器。

## 内力

- `storedMaxQi` 是长期资产，打坐提升。
- 打坐：消耗 `amount` 点当前 Qi，获得 `max 1 (amount / 20 + internalPower / 50)` 点 `storedMaxQi`，消耗 Jing `max 5 (amount / 10)`。
- 上限：`storedMaxQi <= 100 + 10 * (basicInternal + enabledInternal)`。到上限后打坐只回 Qi 不涨上限，提示“内功火候不足”。
- 当前 Qi 必须在战斗外按 `dsQiRegen` 恢复，否则打坐只能打一次。

## 资源闭环

### 恢复

战斗外每个 tick 恢复（战斗内不自然回复，维持现状）：

| 资源 | 每秒恢复 | 加速 |
| --- | --- | --- |
| HP | `0.5 + vit / 30` | 在客舍、本门休息为 3 倍 |
| Qi | `dsQiRegen` | 打坐、吐纳动作；本门休息为 3 倍 |
| Jing | `dsJingRegen` | 睡觉为 3 倍 |

- 战败不扣实战经验和潜能。战败后 HP 置为 1，并带上“重伤”状态：HP 恢复减半，持续 5 分钟或用药治愈。
- 重伤时不能发起战斗。

### 实战经验与潜能的来源

| 来源 | 实战经验 | 潜能 |
| --- | --- | --- |
| 战斗胜利 | `baseExp(R) * rewardScale` | 实战经验的一半 |
| 江湖差事（job，可重复） | 按差事等级与连做次数 | 较多，是潜能的主要来源 |
| 剧情任务（一次性） | YAML 声明 | YAML 声明 |
| 远行路上事件（首次） | YAML 声明 | YAML 声明 |

`QuestReward` 需要增加 `combat_exp` 与 `potential` 两个字段，剧情和差事才能推动成长。

### 战斗奖励

用“武功档次”`R` 比较双方：取角色已启用的拳、剑武功和对应基础功中最高的等级，NPC 可用 YAML `rank` 覆盖。

```text
baseExp(R) = 3 + 7 * R / 10

diff = enemyRank - playerRank
rewardScale =
  diff <= -10 -> 0.1
  diff <= -4  -> 0.5
  diff <=  3  -> 1.0
  diff <= 10  -> 1.3
  otherwise   -> 0.6
```

- 打比自己弱得多的对手几乎没有收益；稍强的对手收益最高。
- 木人、木桩等训练对象声明 `reward_exp_ceiling`：玩家实战经验超过该值后不再获得奖励。建议值 300，大约对应练到 14 级。
- 剧情 Boss 可以用 YAML `reward` 直接写死奖励，不走公式。

### 潜能软上限

```text
potentialCap = 200 + combat_exp / 10
```

超过上限的潜能不再增加，奖励提示“潜能已满”。这样鼓励玩家及时去学，而不是攒着。

## 节奏目标

以下是按本文公式估算的单门武功节奏，用于调参对照。只靠 practice 的时间按精神每秒恢复 1 点估算，没有算 HP 和战斗时间。

| 目标等级 | 实战门槛 | 全靠 learn 的潜能 | 只靠 practice 的 busy 时间（含基础功） | 体验定位 |
| --- | --- | --- | --- | --- |
| 10 | 100 | 约 45 | 约 0.5 小时 | 第一幕到开封落脚 |
| 20 | 800 | 约 155 | 约 2 小时 | 走完第一条远行路 |
| 30 | 2700 | 约 330 | 约 4.5 小时 | 三城门户都认下 |
| 60 | 21600 | 约 1200 | 约 17 小时 | 地域武学大成 |
| 100 | 100000 | 约 3300 | 约 48 小时 | 基础功圆满，长线目标 |

实战经验节奏目标：与自己档次相当的战斗，在 10 级时约 6 场换 1 级实战门槛，30 级时约 15 场，60 级时约 25 场。江湖差事应提供不少于战斗的实战收益，让不爱刷怪的玩家也有路走。

新玩家默认存档的 `combat_exp` 应为 0，不再开局 1000。

这些数字必须用一个 server 端确定性模拟测试固定下来（见“测试”），改公式时同步更新上表。

## 招式解锁

普通招式 `attack_moves` 和主动招式 `active_skills` 都可以声明 `unlock_level`，未声明时默认 1：

```yaml
attack_moves:
  - id: weiyuan_slash
    name: "护镖横斩"
    unlock_level: 1
    damage: 14

active_skills:
  - id: eight_direction_thrusts
    name: "八方连刺"
    unlock_level: 5
    cost: 80
```

- 普通攻击只从已解锁的 `attack_moves` 中选。
- 客户端只展示已解锁的主动招式；`perform` 未解锁的招式会失败。
- 主动招式可声明 `req_arts`，要求玩家已学指定武功。
- 长线武功应在 1/4、1/2、3/4 和满级附近各有一个解锁点，让升级有可见的回报。

## 启用武功

当前同时有 `enable` 和 `prepare` 两个槽：普通攻击的招式从 `prepared` 取，命中、伤害、招架的等级却从 `enabled` 取，两边不同时会出现“出 A 的招、用 B 的威力”。

本设计合并为一个启用槽：

- 每个类型（内功、轻功、剑法、拳法）启用一门已学的具体武功。
- 普通攻击按武器决定类型：持剑用启用的剑法，空手用启用的拳法。
- 派生数值、普通攻击、主动招式都只读启用槽。
- `prepare` 命令保留为 `enable` 的别名，存档里的 `prepared` 读取后合并进 `enabled`。
- 学会新武功时，只有该类型还没有启用武功才自动启用，不覆盖玩家已经做出的选择。

## 秘籍

秘籍是物品：

```yaml
use:
  type: learn_art
  art: weiyuan_sword
  level: 1          # 未学会时直接学到的等级
  min_level: 1      # study 推进熟练度的等级带
  max_level: 10
  quality: 2
  consume: false
```

- `use`：未学会时学会，已学会只显示 `repeat_message`。
- `study`：未学会时学会；已学会且等级在 `[min_level, max_level)` 内时推进熟练度。超出等级带返回“这本书已经读不出新东西”。
- 学习前检查目标武功 `requires`。

## 玩家查询

`{"other":"arts"}` 返回 `ArtsMsg`，每项包含：

- 武功 id、名称、类型、阶、当前等级、最大等级。
- 当前熟练度与本级所需熟练度。
- 是否基础功、基础功依赖、学习要求。
- 已解锁招式与下一个解锁点。
- 下一级的阻碍：实战经验不足、基础功不足（只影响 practice）、或已满级。

```json
{
  "artSummaryId": "weiyuan_sword",
  "artSummaryName": "威远剑法",
  "artSummaryType": "sword",
  "artSummaryLevel": 3,
  "artSummaryProgress": 12,
  "artSummaryNextProgress": 60,
  "artSummaryMaxLevel": 20,
  "artSummaryFoundation": "basic_sword",
  "artSummaryRequirements": [
    {"artRequirementSummaryId":"basic_sword","artRequirementSummaryName":"基础剑法","artRequirementSummaryLevel":1}
  ],
  "artSummaryUnlockedAttackMoves": ["护镖横斩"],
  "artSummaryUnlockedActiveSkills": ["定步斩"],
  "artSummaryNextUnlocks": ["八方连刺"]
}
```

正式 UI 用等级称谓代替数字，数字只放在详情里：

| 等级 | 称谓 |
| --- | --- |
| 1-9 | 初学乍练 |
| 10-19 | 粗通皮毛 |
| 20-34 | 略有小成 |
| 35-49 | 驾轻就熟 |
| 50-69 | 融会贯通 |
| 70-89 | 炉火纯青 |
| 90+ | 登峰造极 |

客户端不翻译武功名、招式名和描述，只翻译固定字段标题与称谓。

## 世界校验

server 启动时拒绝不一致的配置：

- `max_level` 必须为正；`research_from` 在 `1..max_level` 内。
- `foundation` 必须引用存在的基础功。
- `requires.art` 必须存在，`requires.level` 必须为正；`regional` 及以上至少一条大于 1。
- 招式 `unlock_level` 为正且不超过 `max_level`。
- `active_skills[].req_arts` 必须引用存在的武功。
- `Character.teaches` 必须引用存在的武功，可教上限为正且不超过 `max_level`。
- 物品与剧情 `learn_art` 的等级为正且不超过 `max_level`；秘籍等级带满足 `min_level <= max_level`。

## 存档

新增或变化的字段：

- `arts[].progress` 开始真正保存非零值。
- `prepared` 读取后并入 `enabled`，写回时不再写 `prepared`。
- busy 队列是运行态，不保存；断线时丢弃未完成的次数。
- 存档版本加一，迁移函数负责上述合并。

## 当前实现与本设计的差距

| 项 | 当前实现 | 本设计 |
| --- | --- | --- |
| 每次养成 | 每次给满一级熟练度 | 按动作给熟练度，攒满才升级 |
| practice | 只花 Jing，可以练到实战上限 | 受基础功限制，附加 HP/Qi 成本，瓶颈时回流基础功 |
| research | 和 practice 效果相同，只是多花潜能 | 达到 `research_from` 后才能用，突破师父和秘籍的上限 |
| 基础功 | `max(当前, 具体武功等级)` | 按熟练度的一半累积；武馆可教 |
| 实战门槛 | `10 * L^2`，默认存档 1000 | `L^3 / 10`，默认 0 |
| 学习门槛 | 所有武功只要基础功 1 级 | 分三阶，门槛写成真实基础功等级 |
| 战斗奖励 | 只看敌人数值，不比较强弱 | 按档次差缩放，训练对象有上限 |
| 剧情奖励 | 只有钱和物品 | 增加实战经验与潜能 |
| HP/Qi 恢复 | 战斗外不恢复 | 战斗外按派生速度恢复，休息加速 |
| 打坐 | 无上限，但 Qi 回不来所以只能打一次 | 有内功决定的上限，Qi 可恢复 |
| prepare/enable | 两个槽，战斗分别读取 | 合并为一个启用槽 |
| 多次 learn | 整体成功或整体回滚 | busy 队列，逐次结算，失败保留已完成部分 |
| 潜能 | 无上限，几乎无处可花 | learn/research 主要消耗，有软上限 |

## 落地顺序

1. **恢复闭环**：战斗外 HP/Qi 恢复、战败重伤状态。改动最小，没有它连续游玩会卡死。
2. **熟练度与动作分工**：`progressRequired` 改线性、各动作改为给熟练度、practice 受基础功限制并回流、基础功按一半熟练度累积、research 加 `research_from`、打坐加上限。同时把实战门槛改为三次曲线，默认存档 `combat_exp` 改为 0。
3. **奖励**：战斗奖励按档次缩放、训练对象上限、`QuestReward` 增加实战经验和潜能、潜能软上限。给现有剧情节点补奖励。
4. **启用槽合并**与存档迁移。
5. **busy 队列与次数参数**，客户端武学面板加“练 N 次”。
6. **内容分阶**：给现有武功补 `tier` 与真实门槛，师父可教上限按门路层级拆分。
7. 之后接门派/师承（记名、入室）和江湖差事，再到心法。

每一步都要同步更新节奏模拟测试。

## 测试

- 纯函数：`expRequired`、`progressRequired`、各动作的熟练度与成本、基础功回流、打坐上限、`rewardScale`。
- Gameplay：
  - practice 在武功等于基础功时只涨基础功；
  - learn 多次中途精神不足时保留已完成的次数；
  - 训练对象超过 `reward_exp_ceiling` 不再给奖励；
  - 战败后进入重伤状态，不能发起战斗；
  - 战斗外 HP/Qi/Jing 按 tick 恢复。
- 节奏模拟：用确定性脚本模拟“只练”“只学”“边打边学”三种玩家到 10/20/30 级的资源和时间，断言落在“节奏目标”表的区间内。
