# 主线剧情大纲

本文是剧情和内容制作的主线入口。`content-skeleton.md` 负责地图、NPC、任务和城市规模；本文负责剧情因果、玩家动机和长期回响。

世界以明代中叶的制度、城市、交通和江湖结构为蓝本，但朝代、皇帝与年号均为虚构。真实地点可以使用，人物、组织、案名和关键物件均采用改写设定，不直接复刻经典原作。

开封府是中原商路与武林消息交汇的大城，不是天下首都。城中官民正式称“开封”或“府城”，“汴梁”“汴京”只作为古称、诗文与江湖人口中的旧名。少林、武当与五岳诸派可以在同一时代并存；大理段氏则是前朝王族后裔和西南武林旧族，不再拥有当朝王权。

## 核心方向

玩家的江湖从一场偶遇开始，但不被这场偶遇永久绑住。

序章中，玩家在开封城外破庙卷入威远镖局追杀，救下一名灰衣少年，并把他护送到开封城南的威远分局。分局已经遭人血洗，少年决定独自离开。玩家留下水浸路单和威远剑谱，随后从南门进入开封，寻找住处、练功门路和生计。

威远灭门案只是一根埋下的旧线。它不在序章后继续占据任务栏，也不负责解释玩家去洛阳、大理、太湖或雁门的理由。玩家先拥有自己的经历、人脉和选择，等经过较长篇幅后，再以暗记、旧物、传闻或重逢的形式与少年回响。

## 叙事支柱

1. `自由`：主线把玩家推入江湖，但不能长期替玩家决定要做什么。
2. `名`：名声能开门，也能把人钉在别人的说法里。
3. `义`：义气不是接下所有麻烦；知道何时已经尽到承诺，同样重要。
4. `旧物`：秘密先寄存在路单、剑谱、名帖、路契、药方和书信中，不由 NPC 一次讲完。
5. `回响`：旧线再次出现时，应撞上玩家后来建立的身份，而不是把玩家拉回新手状态。

## 世界骨架

### 三座大城

- `开封府`：新手枢纽。提供客舍、武馆、府学、府衙、驿馆、钱庄、茶楼和城市工作。汴梁是其古称。
- `洛阳`：旧都与豪客之城。承接名帖、聚会、白马寺、旧世家和剑法路线。
- `大理`：西南府城。承接商队、段氏旧族、寺门、茶马道和内功奇遇。

### 经典小地点

- `开封城外破庙`：一次性的序章困局。
- `雁门旧道`：开封府巡查、送信和边地见闻，不在开局阶段强绑威远旧案。
- `太湖水榭`：药车、水路、医者、花笺与地方人情。
- `少室山`、`武当山`、`华山道`与五岳诸山：后续门派、武林大会和论剑内容。

## 第一幕：破庙救人

已落内容：`weiyuan_bloody_case`

### 发生的事

1. 玩家在开封城外破庙避雨，遇到重伤老镖师和灰衣少年。
2. 老镖师阻止点火，追兵随即循车辙闯入。
3. 玩家与黑衣人交手，保住庙中二人。
4. 老镖师临终交出三十文盘缠，只求玩家把少年送到开封城南的威远分局门前。
5. 玩家与少年沿汴水官道抵达汴水南渡，不是由剧情直接传送到镖局。
6. 两人进入分局前厅，发现镖旗被砍、账册被夺、镖师尽死。
7. 少年把水浸路单和威远剑谱交给玩家，决定从后院独自离开。

### 分手原则

少年不会承诺近期回来找玩家，也不会解释自己下一步到底做什么。

他可能藏起来，可能调查灭门案，也可能投奔仍可信的人。当前脚本只记录：

```text
weiyuan.youth_separated
weiyuan.route_note_kept
```

这两个 flag 是远期回响的锚点，不会自动开启新的威远任务。

### 玩家为什么可以离开

- 老镖师的托付只到“把少年送到开封城南的威远分局”，玩家已经完成承诺。
- 少年主动选择独行，不再要求玩家保护或查案。
- 玩家没有威远身份，也没有能力在灭门现场对抗未知势力。
- 把证物带离现场、先活下来，是合理选择而不是逃避主线。

### 系统出口

- 学会交谈、战斗、短途护送、剧情移动和任务完成。
- 获得来源明确的三十文盘缠、水浸路单和威远剑谱。
- 抵达开封城南，并从南门进入开封，但不自动接取追查灭门案的后续任务。

## 第二幕：在开封站住

已落内容：`first_steps_kaifeng`

这一幕属于玩家自己，不属于威远镖局。

### 流程

1. 到南门向周引路问路。
2. 在樊楼客舍取得后院房牌，把水浸路单压进箱底。
3. 回南门演武场见梁教头，与练招木人打一场短战。
4. 在府学、铁铺或药铺选择第一份活。
5. 雇主当面给工钱和工筹，任务不再凭空结算房牌、工筹或银钱。

### 角色创建回响

创建角色时选择的出身写入剧情 flag。当前至少在以下场景得到识别：

- 孤儿更熟悉城门与街面生存方式。
- 武学世家的站架会被梁教头看出来。
- 书香或官宦出身在抄书时有不同对白。
- 医药之家在药铺分药时会被识别。

这些差异不改变任务成败，只让世界承认玩家已有的人生。

## 第三幕：自行选择远行

已落内容：`three_city_leads`，玩家可见名为“远行门路”。

### 原则

- 洛阳、大理、太湖不是威远旧案的三条调查分支。
- 玩家只需选择第一次想去的地方，不必把三名接引人依次点一遍。
- 三城路引是实际交通凭证；从开封出发需要找对应接引人同行。
- 三座城市各自先讲自己的生活、人物和矛盾，不能一见面就替远期暗线解释答案。

### 三条路

- `洛阳`：名帖、酒会、剑客、旧契和公开声望。
- `大理`：商队护送、茶马道、段氏旧府与寺门。
- `太湖`：药车、水路、医者、书信和地方势力。

## 雁门旧道：独立江湖差事

已落内容：`yanmen_patrol`

开封府捕房请玩家查看失踪边报。玩家在递铺亭发现马蹄印，在西侧小径制住探子，取回递铺木牌，再返回开封复命领取脚钱。

这一任务当前不揭示威远旧案，也不把木牌写成威远暗记。它的作用是让玩家第一次接触官府差事、野外追踪和有来有回的任务结构。

## 威远旧线如何回归

短期不新增正式任务，只保留制作约束：

1. 第一次回响不能直接让少年现身，可先让玩家在无关事件里见到相似暗记或听见错误传闻。
2. 第二次回响可以让某人认出剑谱或路单，但对方未必可信。
3. 真正重逢应发生在玩家已有师承、人脉或城市立场之后。
4. 少年重现时已经作出自己的选择，可能改名、负伤、依附某方，也可能在调查中犯过错。
5. 重逢不能自动夺走玩家当前路线；帮助、拒绝、交换情报都应成立。

## 内容编写规则

新增剧情 quest 前必须回答：

1. 玩家为什么会接它。
2. 为什么必须去这个地点。
3. 这段内容交付什么人物变化或世界信息。
4. 它实际练习或打开哪个系统。
5. 结束后玩家获得哪些选择，而不是被推去唯一下一站。

如果一段内容主要在解释系统路线，而没有人物欲望、代价或隐瞒，就不应先写进 YAML。
