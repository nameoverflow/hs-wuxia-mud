# 内容骨架规划

本文把此前 MUD 调研落到当前项目的第一版可制作内容骨架。它负责地图、NPC、任务和门派的制作规模；主线因果、玩家动机和后续暗线以 [主线剧情大纲](./story-outline.md) 为准。

## 规模判断

传统武侠 MUD 的成熟世界通常是几十个区域、数千个房间文件。公开 mudlib 粗略统计显示，大型侠客行/炎黄系世界常见 70-90 个 `d/` 顶层区域，疑似房间文件在 4000-5500 量级；较早期 mudlib 也有十几个区域和数百个房间。

当前项目不应一开始追求这个体量。第一阶段目标是做一个 80-120 房间的高密度骨架：

- 一个中心镇，承载商店、武馆、书院、巡捕、马厩、任务入口和门派接引。
- 一个序章区域，继续使用现有冷雨客栈。
- 三个首发门派区域，每个 10-20 个房间。
- 两条野外路线，承载低级战斗、采集、巡查和后续动态 job。
- 少量一次性剧情 quest，用来模拟未来 job/faction 系统的玩法入口。

## 世界入口

现有序章“冷雨客栈”保留为第一幕。玩家不是随机出生在客栈，而是带着半张无名短笺来到渡口：短笺只写“今夜，冷雨客栈，问青衣客”。渡船因雨停航，玩家只能进客栈问人，顺势学习移动、交谈、进房间触发、战斗、剧情完成、物品奖励和秘籍学习。

序章结束后，纸伞客留下的伞骨银针和开场短笺出现同一处暗记：半个“津”字。青衣客把玩家指向北边 `津关镇` 的灰衣引路人。进城的第一动机不是“开新地图”，而是追查短笺来源、找落脚处，并获得下一阶段江湖生活的入口。津关镇是第一版内容枢纽，不直接把玩家送到门派，而是先让玩家：

1. 到镇口听引路人说明。
2. 到武馆确认基础功和师父学习入口。
3. 到书院、药铺或铁匠铺接触第一批工作型任务。
4. 了解三条门派路线，再自行前往门派区域。

## 地点分层

### 中心镇

中心镇承担传统 MUD 城市功能：

- 客栈、茶棚、公告墙：消息、叙事、社交入口。
- 武馆、演武场：基础功、试招、低级师父。
- 药铺、铁匠铺、书院：新手工作和生活技能入口。
- 巡捕房、衙门、仓房：追捕、巡查、送信任务入口。
- 钱庄、当铺、驿站：经济和交通入口。
- 三个门派接引点：只展示方向和风格，不把门派选择做成出生职业。

### 门派区域

首批门派只做内容骨架，不实现正式 `Faction` 类型。师承先由 NPC `teaches` 表达。

- 寒雨门：剑法、轻功、观察、反击。承接冷雨客栈的“听雨”意象。
- 铁衣帮：拳脚、护体、押送、巡查。偏江湖帮会和低门槛新手路线。
- 药王谷：内功、疗伤、解毒、采药。偏辅助和长期资源恢复路线。

正式门派系统落地后，应把这些内容迁移为：

```text
Faction YAML
  -> Teacher YAML/NPC binding
  -> apprentice requirements
  -> betrayal/detach penalties
  -> faction jobs
```

### 野外路线

野外不只是通道，应同时承担：

- 新手危险提示。
- 可战斗 NPC。
- 任务目标刷新点。
- 后续 RoomObject 掉落和采集点。
- 通往更远区域的扩展口。

第一条野外线是 `黑松路`，用于巡捕房追捕任务、低级战斗和未来动态 job。

## 主线节奏

本项目适合“轻主线 + 开放养成”：

```text
冷雨客栈
  -> 看见真相，得到江湖引子
  -> 渡口官道
  -> 津关镇
  -> 武馆确认基础功
  -> 工作/巡查/打探
  -> 三门派接引
  -> 门派学习、野外任务、后续章节
```

传统 MUD 的核心目标不是通关，而是“拜师、练功、做事、游历、碰奇遇”。因此主线只负责把玩家推入江湖，不应长期锁住玩家路线。

这些内容只使用当前已加载 schema：地图、NPC、武功、物品和剧情 quest。门派、循环 job、RoomObject、drop table 和正式拜师惩罚仍属于后续系统工作。

## 后续制作顺序

1. 给津关镇增加更多服务行为：买卖、存钱、修理、治疗。
2. 把“工作/巡查”从一次性 quest 拆成 `JobTemplate` / `JobInstance`。
3. 增加 `Faction` / `Teacher` 配置，迁移三门派师承。
4. 给野外加入 RoomObject 掉落、尸体和归属保护。
5. 扩展第二章剧情：从黑松路追捕引出真正的江湖冲突。
