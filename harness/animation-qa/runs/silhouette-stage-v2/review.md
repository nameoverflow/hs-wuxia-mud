# 剪影交锋 v2 验收

日期：2026-09-06。

**Verdict: Pass。主观体验评分：78/100。** 评分用于本次已接受的“简化剪影 + 克制交锋”目标，不代表连续武术动画或全部设备性能评级。

## 用户期望

保留项目的简化人形剪影，避免完整人物立绘带来的生成不稳定与 MUD 风格违和。完成有蓄势、有力度、有接触与收势的交锋，保持文字主导；agent 应能通过素材生成、数据编排、程序校验和实际回放独立制作与迭代。

## 最终实现

- 原有 v13 body/hair 轮廓复用并机械打包；男女 body 仍共享，female 显示马尾。
- 七类攻击重新安排 ready/preparation/strike/recovery/ready，普通直拳从原来的 1100ms/660ms 命中调整为 620ms/200ms 命中。
- 唯一 BattleClock 驱动采样、命中回调、显示气血、可选声音与结算队列；删除旧 Pixi/GSAP 战斗舞台。
- 背景、直刺、劈扫、上挑、命中、招架与内息笔触由内置 image_gen 生成。生成后只做裁切、缩放、留白、编码和图集拼接。
- 主游戏和 `/battle-lab.html` 共用实际舞台；回放页提供整段交锋、单招、结果分支、profile、暂停、倍速和定位。

## 视觉检查

实际 Chrome 录制，舞台 640×260；8.00 秒原始录像按 16 fps 抽样成三张密集 storyboard，全部检查。另检查了七种攻击的命中截图、390px 手机减弱动态截图与主游戏布局。

1. **动作语义：通过。** 最终 storyboard 001 第二、三行是两次独立拳击，第四、五行展示架势和踢击落空；002 的沉劲掌、调息与挑剑有可辨认的不同姿势。
2. **节奏：通过。** 接近变为短促发力，脚底不再经历统一小跳；001 第二、三行从命中到收势是连续位移回收，保留了短暂站定。姿势本身仍是有限关键画切换。
3. **因果与结果：通过。** 目标在命中前保持待机；闪避先移动，招架保持稳定；002 调息保留对手待机；003 的胜负文字出现在最后一击之后。
4. **连续性：通过。** 初版 DOM 逐 URL 切图在个别第一次播放处出现短暂空图。改为固定 body/hair/VFX 图集并预解码后，最终三张 storyboard 中没有再次观察到人物消失。
5. **层次和风格：通过。** 山水竹影作为低饱和背景；双方分别采用暖纸色和灰青色。减弱命中时的纯白覆盖后，接触瞬间仍能辨别双方。七张接触截图显示剑刺、劈剑、挑剑、踢腿均有对应方向笔触。
6. **手机与减弱动态：通过。** 390px 视口无横向溢出，剪影、动作标签与结果可读；减弱动态模式保留姿势和数字，移除突进、镜头运动、轨迹和残影。

初始录屏中的白屏/回放页加载帧不属于交锋，未作为动画评价对象。`preview.webm` 仅机械裁掉准备与结束后的多余片段，便于直接查看。

## 表达边界

这是有限关键姿态的剪影交锋，不含连续肢体插值；收势会复用已有姿势。当前正式覆盖拳掌与剑术。未来新动作仍需经过相同的图集、行为测试和视觉验收，不能把一次通过当成任意姿态都能自动生成成功。录像/测试未测量全设备帧率，声音仅验证浏览器启用与播放流程。

仓库原有的任务、剧情和测试修改未纳入本次实现，也未重写。
